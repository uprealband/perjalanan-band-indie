# Universe

Folder ini berisi koleksi **Universe**, yaitu interpretasi ulang lagu-lagu UprealBand dalam berbagai konsep, genre, aransemen, dan pendekatan kreatif.

Universe bukan sekadar remix atau cover. Setiap Universe merupakan eksplorasi yang memperluas kemungkinan sebuah lagu tanpa menghilangkan identitas karya aslinya.

Isi folder dapat berupa:
- AI Version
- Orchestra Version
- Acoustic Version
- EDM Version
- Rock Version
- Reggae Version
- Cinematic Version
- Tribute Version
- Experimental Version
- dan berbagai interpretasi kreatif lainnya.

Universe menjadi ruang eksplorasi yang menunjukkan bahwa satu lagu dapat memiliki banyak kehidupan, banyak suasana, dan banyak cerita.
