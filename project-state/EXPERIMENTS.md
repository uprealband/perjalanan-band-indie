# Experiments

## EXP-001
Status: observation recorded

Hypothesis: narrative pages and archive media alone may be sufficient for AI to reconstruct Uprealband history.

Observation: the repository has substantial narrative and evidence infrastructure, but no explicit persistent representation of project decisions, rejected approaches, causal relations, or experiment history.

Implication: narrative plus archive is a strong information base, but does not preserve the reasoning state of the project.

Next test: add explicit project-state structures and later compare AI answers with and without them.

## EXP-002
Status: planned

Hypothesis: explicit entity/event/relation/evidence structures will reduce temporal and causal errors in AI reconstruction.

Method: compare a baseline representation against a structured representation using the same fixed question set.

Candidate measurements:
- factual accuracy
- temporal accuracy
- entity identification
- relation accuracy
- source attribution
- causal reasoning
- hallucination rate
- regression to rejected decisions

No improvement is assumed until measured.
